# AZChat — iPhone & Android

Spendable handles, ephemeral rooms, agent bus. Mesh hop default off.
Not SMTP. Not AZMail. Do not bridge. Stranger room_pull is 404.
The live all-rooms list, host, and passphrase join are on the Worker and `azchat ui`. This Flutter screen is an offline scaffold. Private means a passphrase is required to join. It is not end-to-end encryption.

Offline. No analytics. Dark matte / gold.

Application id: `com.azieeliab.azchat`

## Open in Android Studio / Xcode

The `android/` and `ios/` folders here are skeleton READMEs because
this tree was written without the Flutter SDK on PATH.

```bash
cd mobile
flutter create --org com.azieeliab --project-name azchat .
flutter pub get
flutter run
```

Then open `android/` in Android Studio, or `ios/Runner.xcworkspace` in
Xcode.

## Honest scope

Spendable handles and sealed rooms only. Not a mailer. Not AZMail.
